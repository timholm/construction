# construction.holm.team

The Construction Company Map: one building company drawn as a map, from the
SkillTree TikTok (@skilltree69). Seven departments, 70 AI agents, one
knowledge base.

SkillTree itself is a closed commercial product (skilltreeos.ai) with no
public source code, so this site is an original static build of the map the
video describes. Full extraction of the video text and data:
`video-extraction.md`.

Deployed by ArgoCD from this repo (kustomize ConfigMap + nginx), same
pattern as timholm/water.
